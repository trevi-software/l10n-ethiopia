This module defines an Ethiopian leave report that can also be used as leave request form. 
It extends the hr.leave model to include Ethiopian date conversions and customizations specific to
Ethiopian labor laws, such as excluding rest days from leave calculations. The report template is
customized to display dates in the Ethiopian calendar format and includes additional fields for better clarity.
